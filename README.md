# ZWSOFT製品紹介ページ リニューアル提案モック

> **本モックは非公式の自主制作提案です。**
> 採用選考で提示するために個人で制作したもので、株式会社オズクリエイション様・ZWSOFT社から依頼を受けたものではありません。
> 掲載している製品情報は、2026年9月18日時点で公開されていた情報（osc-inc.co.jp）をもとにしています。

対象ページ：https://www.osc-inc.co.jp/zwsoft-products/

## 起動方法

ビルドは不要です（HTML / CSS / JavaScript のみ。npm依存なし）。

```bash
python -m http.server 3011
```

ブラウザで http://127.0.0.1:3011/ を開きます。`index.html` を直接開いても動作します（Webフォントの読み込みのみネット接続が必要）。

### デモ用URL

| URL | 動作 |
|---|---|
| `/?product=zw3d` | ZW3D の詳細モーダルを開いた状態で表示 |
| `/?product=zwcad` | ZWCAD の詳細モーダル |
| `/?product=zwcad-mfg` | ZWCAD MFG の詳細モーダル |
| `/?static` | スクロール演出を省略して全要素を表示（撮影用） |

## 主なインタラクション

- **ヒーロー**：左にコピー・CTA、右にキービジュアル（現実の街並み→設計データの対比）。画像は右端まで広げ、左端をフェードさせてコピー側となじませる。読み込み時に右から現れ、スクロールでわずかにパララックス（動きを減らす設定では無効）。製品への導線はページ下部の製品一覧・比較表に集約している。
- **スクロールで出現**：見出し・カード・比較表の各行が IntersectionObserver で順に表示される。2D図面のイラストは線が描かれていく。
- **課題 → 製品**：課題を選ぶと、関連する製品カードへスクロールし、そのカードを強調表示する。
- **製品詳細モーダル**：クリックしたカードの位置から画面が広がる（clip-path による container transform ＋ 図版のFLIP）。閉じるとカードの位置へ戻る。
  - Escキー／閉じるボタン／背景クリックで閉じる。ネイティブの `<dialog>` を使い、フォーカスの閉じ込めと、閉じた後のフォーカス復帰に対応。背景スクロールも固定する。
  - ZW3Dはスライダーやドラッグでイラストを回転できる。ZWCADのカードはカーソル位置に十字線を表示する。
- **比較表**：製品名を選ぶと詳細モーダルが開く。スマホでは項目列を固定したまま横スクロールできる。
- **`prefers-reduced-motion`**（動きを減らす設定）では、アニメーションを最小限にする（フェードのみ）。

## CTAの接続先

| CTA | 接続先 |
|---|---|
| 製品を比較する | ページ内の比較表 |
| 詳しく見る／比較表の製品名 | 製品詳細モーダル |
| 導入相談 | 公式「お問合せ」ページ（別タブ） |
| 30日間無料体験版 | 公式 `/zwtrial/`（別タブ） |
| 資料請求 | **資料請求専用の公式ページは確認できなかった**ため、非公式モックであることを明記したデモ画面を表示し、お問合せページ・体験版ページへ案内する |

問い合わせフォームは実装していません。個人情報を収集・送信する処理もありません。

## 検証

```bash
node scripts/shoot.mjs
```

- 1440 / 768 / 390px で、ファーストビュー、ヒーローの分解状態、製品一覧、比較表、3製品のモーダル、ページ全体を撮影
- 横スクロールの有無を `screenshots/overflow-report.json` に出力（3サイズとも、ページ幅がビューポート幅以下であることを確認済み）

## 今後の拡張

- 現状は依存なしの静的サイトのため、そのまま Vercel に静的デプロイできます。
- Next.js + TypeScript へ移行する場合は、`js/data.js` を型付きのデータ、`js/visuals.js` をSVGコンポーネントに置き換える想定です。
- 公式の製品画像・操作画面は、利用許諾を得たうえで `card-visual` 部分と差し替えます。
